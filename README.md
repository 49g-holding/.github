# 49g-holding/.github

Organization-level defaults and profile for the **49G Holding Ltd** GitHub organization ([github.com/49g-holding](https://github.com/49g-holding)).

## Contents

| Path | Purpose |
| --- | --- |
| `profile/README.md` | Organization profile shown on the org page (only while this repository is public) |
| `.github/ISSUE_TEMPLATE/` | Default issue templates inherited by org repositories that lack their own |
| `.github/PULL_REQUEST_TEMPLATE.md` | Default pull request template |
| `CONTRIBUTING.md` | Org-wide contribution conventions |
| `SECURITY.md` | Vulnerability reporting policy |
| `docs/BRANCH_PROTECTION.md` | Recommended branch protection settings, applied manually by an org owner |
| `.github/CODEOWNERS` | Ownership of this repository itself |

This repository carries org profile and templates only. The engineering rulebook of the estate lives in `49g-standards`; where the two could overlap, `49g-standards` governs.

## Status

**PRELAUNCH.** Nothing in it describes a launched, licensed, or operating service. This repository is public so that GitHub shows the organization profile and applies these defaults across the organization; its texts passed the publication decision of the organization's owner on 27 October 2026, with the public release of 49GAION. Every later change to its texts is a publication decision of the same kind.
